# الحفظ التلقائي — للعميل

التطبيق على **VPS دائم**: https://rekaz.wadnooh.com  
قاعدة SQLite على قرص السيرفر + نسخ احتياطي إضافي تلقائي إلى **Amazon S3**.

| | |
|--|--|
| التطبيق | https://rekaz.wadnooh.com |
| قرص البيانات | `/opt/rekaz/data` (دائم) |
| التخزين السحابي | Bucket: `rekaz-alenjaz-backups` |
| المنطقة | `eu-north-1` (Stockholm) |
| المجلد | `rekaz-backups/` |

---

## 1) ماذا تفعل أنت؟

**لا شيء.** لا توجد صفحة «حفظ البيانات» في النظام — الحفظ يعمل تلقائياً في الخلفية:

1. نسخة محلية تحت `/opt/rekaz/data/backups`
2. رفع إلى Amazon S3 في المجلد `rekaz-backups/`
3. تكرار دوري + بعد التعديلات المهمة

إذا احتجت ملف ZIP على جهازك (نسخة إضافية)، اطلبه من مسؤول التشغيل.

---

## 2) التحقق السريع (اختياري)

افتح `/health` وتأكد أن:

- `auto_backup.enabled` = true
- `auto_backup.last_s3_ok` = true (عند ربط Amazon S3)
- `storage.data_persistent` = true
- `features.backups_ui` = false

---

## 3) الاستعادة

لا تتم من واجهة المستخدم. عند الحاجة الطارئة يتولاها مسؤول التشغيل عبر أدوات السيرفر (CLI) مع إنشاء حفظة أمان أولاً.

إذا كانت القاعدة فارغة/جديدة عند الإقلاع ووُجدت حفظات على S3، يستعيد النظام أحدث حفظة تلقائياً (`AWS_S3_AUTO_RESTORE=1`) — **دون مسح قاعدة فيها بيانات عمل حقيقية**.

---

## 4) ثبات البيانات على VPS

البيانات الأساسية على قرص السيرفر (`RAKAZ_DATA_DIR=/opt/rekaz/data`) وتبقى بعد إعادة التشغيل وإعادة النشر.  
Amazon S3 نسخة احتياطية إضافية تلقائية.

---

## 5) إعدادات السيرفر (للمسؤول فقط)

في `/etc/rekaz.env` (بدون نشرها علناً):

```text
AWS_ACCESS_KEY_ID=...
AWS_SECRET_ACCESS_KEY=...
AWS_S3_BUCKET=rekaz-alenjaz-backups
AWS_S3_REGION=eu-north-1
AWS_S3_PREFIX=rekaz-backups
AUTO_BACKUP=1
AWS_S3_AUTO_RESTORE=1
AUTO_BACKUP_ACTIVITY_SECONDS=45
BACKUP_KEEP_LOCAL=30
BACKUP_KEEP_S3=40
RAKAZ_DATA_DIR=/opt/rekaz/data
TRIAL_MODE=1
```

استعادة طارئة (CLI على السيرفر):

```bash
cd /opt/rekaz
sudo -u rekazapp /opt/rekaz/.venv/bin/python tools/restore_backup.py --list
sudo -u rekazapp /opt/rekaz/.venv/bin/python tools/restore_backup.py --export-zip /tmp/rekaz.zip
```

---

## 6) ملخص سريع

| العملية | أين؟ | تدخل يدوي؟ |
|---------|------|------------|
| الحفظ المحلي على السيرفر | قرص VPS | لا (تلقائي صامت) |
| الحفظ السحابي | VPS → Amazon S3 | لا (تلقائي صامت) |
| تنزيل ZIP لجهازك | عبر مسؤول التشغيل عند الحاجة | اختياري |
| الاستعادة | CLI تشغيلي على السيرفر | عند الطوارئ فقط |
