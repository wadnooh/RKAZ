# حماية جهاز المبرمج (التحكم البرمجي)

يطبق على **التعديلات البرمجية/الهيكلية** فقط (لا يعيق الإدارة اليومية ولا إدخال الأعطال):

| مقفول بدون جهاز رئيسي / تحقق (wadnooh) | مفتوح للمدير/الموظفين حسب صلاحياتهم |
|----------------------------------------|-------------------------------------|
| إدارة التبويبات المخصصة | إدارة المستخدمين والأدوار والصلاحيات |
| استيراد/تفعيل بنود العقد (BOQ) | إدخال/تعديل الأعطال |
| أي تغيير لهيكل البرنامج | سجلات الأقسام والوحدات والتصدير |

**من يرى تبويبات «جهاز المبرمج» / «تحقق المبرمج»:** حساب `wadnooh` فقط — المدير العادي لا يراها والوصول المباشر للرابط مرفوض.

**بريد الموافقة المعتمد فقط:**
- `wadnooh@gmail.com`
- `wadnooh@wadnooh.com`

---

## 1) تسجيل الجهاز الرئيسي

1. أسرار السيرفر في `/etc/rekaz.env`: `PROGRAMMER_BOOTSTRAP_CODE` و `PROGRAMMER_CHANGE_PIN` و `SMTP_*`.
2. `sudo systemctl restart rekaz`
3. من **الجهاز المعتمد** سجّل دخول بالحساب المخفي `wadnooh` فقط.
4. افتح: https://rekaz.wadnooh.com/admin/programmer/device
5. اضغط **إرسال** / **إعادة إرسال** ليصلك رمز التهيئة على `wadnooh@gmail.com` و `wadnooh@wadnooh.com`، ثم الصقه في حقل «رمز التهيئة» وسجّل الجهاز.

من هذا الجهاز تصبح التعديلات البرمجية مباشرة.

**الحساب المخفي:** `wadnooh` — لا يظهر في قائمة المستخدمين لأي شخص، وهو الحساب الرئيسي للمراقبة والإصلاح بصلاحيات كاملة.

---

## 2) التعديل من جهاز آخر (رمز البريد إلزامي)

أثناء عمل SMTP **لا يُقبل أي مسار يتجاوز البريد**.

1. افتح `/admin/programmer/verify` بحساب `wadnooh`
2. في صفحة التحقق يظهر دائماً **إرسال رمز التحقق** و**إعادة إرسال رمز التحقق** (بعد أول إرسال انتظر 60 ثانية قبل إعادة الإرسال) → تصل **رسالة واحدة** فيها معاً:
   - رمز التحقق (OTP)
   - رمز التغيير (`PROGRAMMER_CHANGE_PIN`)
   إلى `wadnooh@gmail.com` و `wadnooh@wadnooh.com`
3. أدخل معاً: كلمة مرور الحساب + `PROGRAMMER_CHANGE_PIN` + **رمز البريد**
4. بعد النجاح: تعديل برمجي لمدة **~30 دقيقة**.

**استثناء الجهاز الرئيسي:** بعد تسجيله لا يلزم رمز بريد لكل تعديل.

**طوارئ SSH فقط إذا تعطّل SMTP تماماً:**

```bash
cd /opt/rekaz
sudo -u rekazapp /opt/rekaz/.venv/bin/python tools/programmer_approve.py
```

إذا كان SMTP يعمل يرفض السكربت توليد رمز (الخروج برمز 2).

---

## 3) الاستعادة عند القفل (SSH)

```bash
cd /opt/rekaz
sudo -u rekazapp /opt/rekaz/.venv/bin/python tools/programmer_reset_devices.py --yes
```

ثم أعد تسجيل الجهاز الرئيسي (القسم 1).

عرض/تدوير الأسرار (بدون مشاركتها علناً):

```bash
sudo grep -E '^(PROGRAMMER_|SMTP_)' /etc/rekaz.env | sed 's/=.*/=***/'
sudo systemctl restart rekaz
```

---

## 4) متغيرات البيئة

```text
PROGRAMMER_BOOTSTRAP_CODE=...
PROGRAMMER_CHANGE_PIN=...
PROGRAMMER_EMAILS=wadnooh@gmail.com,wadnooh@wadnooh.com
SMTP_HOST=...
SMTP_PORT=...
SMTP_USER=...
SMTP_PASS=...
SMTP_FROM=...
SMTP_SSL=...   # أو SMTP_TLS=1 للمنفذ 587
```

لا تضع هذه القيم في Git.
