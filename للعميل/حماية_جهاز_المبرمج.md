# حماية جهاز المبرمج (التحكم الإداري)

يطبق على **التعديلات الهيكلية** فقط (لا يعيق إدخال الأعطال أو العمل اليومي للموظفين):

| مقفول بدون جهاز رئيسي / تحقق | مفتوح للموظفين حسب صلاحياتهم |
|-------------------------------|-------------------------------|
| إدارة المستخدمين والأدوار | إدخال/تعديل الأعطال |
| إدارة التبويبات المخصصة | سجلات الأقسام والوحدات |
| استيراد/تفعيل بنود العقد (BOQ) | التصدير والبحث والعرض |

الدور المعني: **`admin` (مدير النظام = المبرمج)**.

**بريد الموافقة المعتمد فقط:**
- `wadnooh@gmail.com`
- `wadnooh@wadnooh.com`

---

## 1) تسجيل الجهاز الرئيسي

1. أسرار السيرفر في `/etc/rekaz.env`: `PROGRAMMER_BOOTSTRAP_CODE` و `PROGRAMMER_CHANGE_PIN` و `SMTP_*`.
2. `sudo systemctl restart rekaz`
3. من **الجهاز المعتمد** سجّل دخول كـ `admin`.
4. افتح: https://report.ralenjaz.com/admin/programmer/device
5. أدخل رمز التهيئة `PROGRAMMER_BOOTSTRAP_CODE`.

من هذا الجهاز تصبح التعديلات الإدارية مباشرة.

---

## 2) التعديل من جهاز آخر (رمز البريد إلزامي)

أثناء عمل SMTP **لا يُقبل أي مسار يتجاوز البريد**.

1. افتح `/admin/programmer/verify`
2. اضغط **أرسل رمز التحقق إلى بريدي** → يصل الرمز فقط إلى:
   - `wadnooh@gmail.com`
   - `wadnooh@wadnooh.com`
3. أدخل معاً: كلمة مرور الحساب + `PROGRAMMER_CHANGE_PIN` + **رمز البريد**
4. بعد النجاح: تعديل إداري لمدة **~30 دقيقة**.

**استثناء الجهاز الرئيسي:** بعد تسجيله لا يلزم رمز بريد لكل تعديل.

**طوارئ SSH فقط إذا تعطّل SMTP تماماً:**

```bash
cd /opt/rekaz
sudo -u rekazapp /opt/rekaz/.venv/bin/python tools/programmer_approve.py
```

إذا كان SMTP يعمل يرفض السكربت توليد رمز (الخروج برمز 2).

---

## 3) الاستعادة عند القفل (SSH)

```bash
cd /opt/rekaz
sudo -u rekazapp /opt/rekaz/.venv/bin/python tools/programmer_reset_devices.py --yes
```

ثم أعد تسجيل الجهاز الرئيسي (القسم 1).

عرض/تدوير الأسرار (بدون مشاركتها علناً):

```bash
sudo grep -E '^(PROGRAMMER_|SMTP_)' /etc/rekaz.env | sed 's/=.*/=***/'
sudo systemctl restart rekaz
```

---

## 4) متغيرات البيئة

```text
PROGRAMMER_BOOTSTRAP_CODE=...
PROGRAMMER_CHANGE_PIN=...
PROGRAMMER_EMAILS=wadnooh@gmail.com,wadnooh@wadnooh.com
SMTP_HOST=...
SMTP_PORT=...
SMTP_USER=...
SMTP_PASS=...
SMTP_FROM=...
SMTP_SSL=...   # أو SMTP_TLS=1 للمنفذ 587
```

لا تضع هذه القيم في Git.
