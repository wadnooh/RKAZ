# حماية جهاز المبرمج (التحكم الإداري)

يطبق على **التعديلات الهيكلية** فقط (لا يعيق إدخال الأعطال أو العمل اليومي للموظفين):

| مقفول بدون جهاز رئيسي / تحقق | مفتوح للموظفين حسب صلاحياتهم |
|-------------------------------|-------------------------------|
| إدارة المستخدمين والأدوار | إدخال/تعديل الأعطال |
| إدارة التبويبات المخصصة | سجلات الأقسام والوحدات |
| استيراد/تفعيل بنود العقد (BOQ) | التصدير والبحث والعرض |

الدور المعني: **`admin` (مدير النظام = المبرمج)**.

---

## 1) تسجيل الجهاز الرئيسي

1. اضبط الأسرار على السيرفر في `/etc/rekaz.env` (انظر أدناه).
2. أعد تشغيل الخدمة: `sudo systemctl restart rekaz`
3. من **الجهاز المعتمد** سجّل دخول كـ `admin`.
4. افتح: https://report.ralenjaz.com/admin/programmer/device
5. أدخل **رمز التهيئة** `PROGRAMMER_BOOTSTRAP_CODE` واضغط تسجيل.

يُحفظ اعتماد المتصفح في كوكي آمن طويل الأمد. من هذا الجهاز تصبح التعديلات الإدارية مباشرة.

---

## 2) التعديل من جهاز آخر

1. على VPS عبر SSH:
   ```bash
   cd /opt/rekaz
   sudo -u rekazapp /opt/rekaz/.venv/bin/python tools/programmer_approve.py
   ```
2. انسخ الرمز الظاهر (صالح ~10 دقائق، لمرة واحدة).
3. من الجهاز الآخر افتح: `/admin/programmer/verify`
4. أدخل معاً:
   - كلمة مرور حساب المبرمج
   - `PROGRAMMER_CHANGE_PIN`
   - رمز الموافقة من الخطوة 1
5. بعد النجاح يُسمح بالتعديل **~30 دقيقة** ثم يلزم التحقق مجدداً.

رسائل الواجهة: «التعديل من الجهاز الرئيسي فقط» / «يلزم تحقق المبرمج».

---

## 3) الاستعادة عند القفل (SSH فقط — لا تُقفل نهائياً)

إذا ضاع الجهاز الرئيسي أو سُحبت الكوكيز:

```bash
cd /opt/rekaz
sudo -u rekazapp /opt/rekaz/.venv/bin/python tools/programmer_reset_devices.py --yes
```

ثم أعد تسجيل الجهاز الرئيسي (القسم 1) برمز التهيئة.

**عرض/تدوير الأسرار بدون طباعتها في الدردشة:**

```bash
sudo grep -E '^PROGRAMMER_' /etc/rekaz.env
# لتدوير رمز:
# عدّل القيمة يدوياً في /etc/rekaz.env ثم:
sudo systemctl restart rekaz
```

---

## 4) متغيرات البيئة

في `/etc/rekaz.env`:

```text
PROGRAMMER_BOOTSTRAP_CODE=...   # لتسجيل/إعادة ربط الجهاز الرئيسي
PROGRAMMER_CHANGE_PIN=...       # جزء من تحقق الجهاز الثانوي
```

لا تضع هذه القيم في Git ولا تشاركها علناً.

---

## ملاحظات

- موظفو `مشرف` / `مدخل بيانات` / `مراقب` غير متأثرين بهذا القفل.
- لا يمس مشروع RTCREPORT (`/opt/weeklyreport`).
- الواجهة: `/admin/programmer/device` و `/admin/programmer/verify` (رابط من صفحة المستخدمين).
