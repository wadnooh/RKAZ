# الروابط للعميل — مراجعة وضبط

## 1) رابط عام يعمل الآن من أي جهاز (موصى به للمراجعة)

```
https://hunt-alternatives-guests-troy.trycloudflare.com
```

صفحة الدخول:

```
https://hunt-alternatives-guests-troy.trycloudflare.com/login
```

| الحقل | القيمة |
|--------|--------|
| المستخدم | `admin` |
| كلمة المرور | `admin123` |

> هذا الرابط يعمل طالما جهاز التشغيل مفتوح وملف النفق شغّال.  
> لإعادة إنشائه لاحقاً: شغّل `تشغيل رابط عام للعميل.bat` وانسخ الرابط الجديد.

---

## 2) رابط Render (بدون جهازك — قد ينام على المجاني)

```
https://rekaz-alenjaz.onrender.com/login
```

على الخطة المجانية قد يظهر Not Found على الجوال أو يتأخر دقيقة.  
للاستخدام الدائم للعميل: رقِّ الخدمة في Render إلى **Starter** حتى لا تنام.

---

## ماذا ترسل للعميل الآن؟

1. رابط Cloudflare أعلاه  
2. `admin` / `admin123`  
3. اطلب منه المراجعة وتسجيل الملاحظات
