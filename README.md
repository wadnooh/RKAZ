## حفظ البيانات (تلقائي صامت)

لا توجد صفحة `/admin/backups` ولا تبويب «حفظ البيانات» في الواجهة.  
الحفظ يعمل تلقائياً: ZIP محلي تحت مجلد البيانات + رفع إلى **Amazon S3** عند توفر المفاتيح، مع تقليم الأرشيف القديم.

استعادة طارئة للمسؤول فقط: `tools/restore_backup.py` على السيرفر.

### الاستضافة الحالية (VPS دائم)

- السيرفر: نفس VPS المستخدم لـ RTCREPORT — الدومين الرسمي `report.ralenjaz.com` (منفصل عن `report.rtcco.org`)
- SQLite دائم على القرص: `RAKAZ_DATA_DIR=/opt/rekaz/data` (يبقى بعد إعادة التشغيل والنشر)
- نسخ احتياطي إضافي إلى **Amazon S3** في الخلفية
- الخدمة: `systemd` (`rekaz.service`) + nginx + HTTPS

المسار المحلي للحفظات: `instance/backups/...` أو تحت `RAKAZ_DATA_DIR` في الإنتاج  
سجل التشغيل: `.../backups/.auto_backup.log`
