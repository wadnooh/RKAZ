## حفظ البيانات (للتطوير والمتابعة)

من داخل النظام: **المستخدمون / الإعدادات → حفظ البيانات**

أو مباشرة: `/admin/backups`

### مرحلة التجربة (Render Free حالياً)

- `TRIAL_MODE=1` في `render.yaml`
- أنشئ حفظة ونزّل ZIP إلى جهازك بانتظام
- عند اختفاء البيانات بعد Redeploy: ارفع ZIP واسترجعه من نفس الشاشة
- بعد الاعتماد: Disk مدفوع + `RAKAZ_DATA_DIR=/var/data` + `TRIAL_MODE=0`

المسار المحلي للحفظات: `instance/backups/YYYY/MM/DD/...`
