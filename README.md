# شركة ركاز الإنجاز للمقاولات

نظام متابعة الأعمال العام — مكتب خدمات خريص

## رابط سحابي للمراجعة (الأفضل للعميل)

اضغط الزر لنشر نسخة مراجعة على السحابة برابط يفتح من أي جهاز:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/wadnooh/rekaz)

أو افتح مباشرة:

https://render.com/deploy?repo=https://github.com/wadnooh/rekaz

### بعد النشر

1. انتظر حتى تصبح الحالة **Live**
2. انسخ الرابط (مثال: `https://rekaz-alenjaz.onrender.com`)
3. أرسله للعميل للمراجعة والضبط

### دخول المراجعة

- المستخدم: `admin`
- كلمة المرور: `admin123`

> الخطة المجانية قد تدخل في سكون بعد فترة عدم استخدام؛ أول فتح بعدها قد يتأخر نصف دقيقة تقريباً.
